1. Overview & scope

spend&Track (internally "spendAI") lets a user log expenses in plain text such as 250 uber, auto-categorises them (keyword rules first, Gemini AI as a fallback), shows monthly statistics, a category doughnut chart and a 10-day trend chart, tracks per-category budget limits with alerts, and answers natural-language questions about spending through Gemini. It can be used with an account (email/password or Google) or as a guest whose data never leaves the browser. It is installable as a PWA.

3. Backend request lifecycle

Every HTTP request to the FastAPI app passes through the same pipeline. Middleware is registered in app/main.py (Starlette runs the last-added first, so they are added innermost → outermost).

Browser — api/index.js request interceptor attaches Authorization: Bearer <spendai_token>frontend/src/api/index.js · api.interceptors.request
▼
HelmetMiddleware — adds security headers (CSP, HSTS, X-Frame-Options, nosniff …)app/middleware/express.py
▼
CORSMiddleware — allows CLIENT_URL with credentials; answers every OPTIONS preflight with 204 directlyapp/middleware/express.py
▼
ExpressRoutingMiddleware — strips a trailing slash; serves HEAD via the GET route with an empty bodyapp/middleware/express.py
▼
BodyParserMiddleware — parses application/json into request.state.body; >10 KB or invalid JSON → 500 {"error":"Internal server error"}app/middleware/express.py · utils/http.py body()
▼
RateLimitMiddleware — in-memory per-IP: 100 req / 15 min on /api, 20 / 15 min on /api/auth; over limit → 429 + Retry-Afterapp/middleware/express.py · _Limiter.hit()
▼
ErrorHandlerMiddleware — catches any unhandled exception → 500 JSONapp/middleware/express.py
▼
Router match (routes/*.py) → Depends(auth_middleware) for protected routes: decode JWT (HS256/384/512), load user row, set request.state.user; failures raise ApiError(401, …)app/routes/*.py · app/middleware/auth.py
▼
Controller — validates input with utils/js.py, runs SQL with db.query(), returns send(status, json)app/controllers/*_controller.py
▼
PostgreSQL — results come back as dicts; NUMERIC / BIGINT / UUID as strings, timestamps as ISO-8601 UTC stringsapp/config/db.py · _register_loaders, _JsDateLoader
▼
Response — JsJSONResponse serialises like JSON.stringify; ApiError → {"error": msg}; unknown route → 404 {"error":"Route not found"}app/utils/http.py · app/main.py api_error_handler / not_found_handler
Why so much "Express" logic? backend-fastapi is a drop-in port of the original Express API: same URLs, JSON shapes, status codes, JWTs and bcrypt hashes. That is why the React frontend works against it with zero changes, and why helpers such as utils/js.py reproduce JavaScript semantics (truthy, parseFloat, isNaN).

11. Observations & notes

  • Gemini key is a frontend build variable. REACT_APP_GEMINI_API_KEY is bundled into the public JavaScript, so anyone can read it. For production, move Gemini calls behind a FastAPI endpoint (e.g. POST /api/ai/parse, /api/ai/ask) and keep the key server-side.
  • Per-user key is unused. users.gemini_api_key and PATCH /api/auth/api-key still exist, but no page calls updateApiKey any more (Settings no longer has the key field).
  • Endpoints without UI: PUT /api/expenses/{id} (edit expense) and DELETE /api/budgets/{category} (remove budget) are implemented in backend and API client but not exposed in the Dashboard.
  • Two categorisers. Dashboard.parseLocal and utils/gemini.localCategorize have overlapping but different keyword lists; consolidating them into utils/ would keep categories consistent.
  • Category spelling. "Grocerries" is used as a category key in several places (CAT_ICONS, CAT_COLORS, seeds, parser); renaming requires a data migration for existing rows.
  • Root docker-compose.yml and bin/*.sh still start the Node backend. Use backend-fastapi/docker-compose.yml for the React + FastAPI stack.
  • Rate limiting is in-memory and per process; with multiple workers/instances each keeps its own counters.
  • Timezone. date is TIMESTAMP (no zone); month/day grouping happens in the DB server's timezone while the guest store and TrendChart use the browser's local time.
